# 🧪 GMTrip 유저 플로우 테스트 가이드 (프론트엔드)

## 📋 전체 유저 플로우

```
1. 랜딩 페이지 접속 (/)
   → 카카오 로그인 버튼 클릭
   
2. 카카오 로그인 완료
   → 메인 페이지로 이동 (/main)
   
3. "여행 계획하기" 클릭
   → 여행 정보 입력 1 (/input-trip-info1)
   → 강원도 지도에서 지역 선택
   
4. 여행 정보 입력 2 (/input-trip-info2)
   → 여행 기간, 동행인, 테마 선택
   
5. 장소 선택 (/select-places)
   → 카카오 맵에서 장소 선택
   → 경로 최적화
   
6. 현재 여행 페이지 (/current-trip)
   → 미션 목록 확인
   → 미션 클릭
   
7. 미션 상세 (/mission/[id])
   → 미션 수행 (사진 업로드 등)
   → 포인트 획득
   
8. 여행 완료
   → 아카이브 자동 저장
   
9. 내 아카이브 (/my-archive)
   → 완료된 여행 확인
   → 상세 페이지에서 추억 확인
```

## 🚀 실제 테스트 방법

### 1단계: 서버 시작
```bash
cd /Users/minseokjeong/workspace/gmtrip/frontend
npm run dev
```

브라우저에서 http://localhost:5173 접속

### 2단계: 랜딩 페이지
✅ **확인 사항**:
- [ ] 로고가 표시되는가?
- [ ] 히어로 섹션이 아름답게 보이는가?
- [ ] "카카오로 3초만에 시작하기" 버튼이 있는가?
- [ ] 기능 소개 섹션 (6개 카드)이 보이는가?
- [ ] 스크롤 애니메이션이 작동하는가?

**액션**: 카카오 로그인 버튼 클릭

### 3단계: 로그인 (더미 사용자)
✅ **확인 사항**:
- [ ] 로그인 후 메인 페이지로 리다이렉트되는가?
- [ ] 상단 네비게이션에 사용자 정보가 표시되는가?

### 4단계: 메인 페이지 (/main)
✅ **확인 사항**:
- [ ] "진행 중인 여행" 섹션이 보이는가?
- [ ] "둘러보기" 섹션에 다른 사용자의 여행이 보이는가?
- [ ] 하단 네비게이션 바가 있는가?
  - 홈, 여행계획, 둘러보기, 아카이브, 마이페이지

**액션**: "여행 계획하기" 버튼 클릭

### 5단계: 여행 정보 입력 1 (/input-trip-info1)
✅ **확인 사항**:
- [ ] 강원도 지도 SVG가 표시되는가?
- [ ] 지역 클릭 시 하이라이트되는가?
- [ ] "다음" 버튼이 있는가?

**액션**: 
1. 강릉시 클릭 (지도에서)
2. "다음" 버튼 클릭

### 6단계: 여행 정보 입력 2 (/input-trip-info2)
✅ **확인 사항**:
- [ ] 동행인 선택 (나홀로, 연인과, 친구와, 가족과)
- [ ] 날짜 선택 (시작일, 종료일)
- [ ] 여행 테마 1 선택 (자연과 힐링, 맛집 탐방 등)
- [ ] 여행 테마 2 선택
- [ ] 모든 정보 입력 시 "미션 추천 받기" 버튼 활성화

**액션**:
1. "가족과" 선택
2. 날짜 선택 (예: 2025-01-15 ~ 2025-01-20)
3. 테마 1: "자연과 힐링"
4. 테마 2: "맛집 탐방"
5. "미션 추천 받기" 클릭

### 7단계: 장소 선택 (/select-places)
✅ **확인 사항**:
- [ ] 카카오 맵이 로드되는가?
- [ ] 추천 장소 마커가 표시되는가?
- [ ] 하단 바텀 시트가 있는가?
- [ ] 장소 선택 시 마커 색상이 변경되는가?
- [ ] "경로 최적화" 버튼이 있는가?

**액션**:
1. 추천 장소 3~5개 선택
2. "경로 최적화" 버튼 클릭

### 8단계: 경로 결과 (/route-result)
✅ **확인 사항**:
- [ ] 선택한 장소들이 순서대로 표시되는가?
- [ ] 지도에 경로가 그려지는가?
- [ ] "여행 시작하기" 버튼이 있는가?

**액션**: "여행 시작하기" 클릭

### 9단계: 현재 여행 (/current-trip)
✅ **확인 사항**:
- [ ] 여행 커버 이미지가 표시되는가?
- [ ] 여행 진행률 (65%)이 표시되는가?
- [ ] 미션 목록 (6개)이 표시되는가?
- [ ] 각 미션에 포인트가 표시되는가?
- [ ] 완료된 미션에 체크 아이콘이 있는가?

**액션**: 첫 번째 미션 ("3컷 여행 요약") 클릭

### 10단계: 미션 상세 (/mission/m1)
✅ **확인 사항**:
- [ ] 미션 헤더 (그라디언트 배경)가 아름다운가?
- [ ] 미션 제목, 설명, 포인트가 표시되는가?
- [ ] 사진 업로드 UI (3개 슬롯)가 있는가?
- [ ] "사진 업로드" 버튼이 있는가?

**액션**:
1. "사진 업로드" 버튼 클릭
2. 사진 3장 선택 (갤러리에서)
3. "제출하기" 버튼 클릭
4. alert: "250P 획득!" 확인
5. "/current-trip"으로 자동 이동

### 11단계: 미션 완료 확인
✅ **확인 사항**:
- [ ] 완료한 미션에 체크 아이콘이 표시되는가?
- [ ] 여행 진행률이 업데이트되었는가?

**액션**: 다른 미션들도 2~3개 더 완료

### 12단계: 포인트 확인 (/points)
✅ **확인 사항**:
- [ ] 획득한 포인트 총합이 표시되는가?
- [ ] 포인트 히스토리가 표시되는가?
- [ ] 각 항목에 미션 이름과 포인트가 있는가?

### 13단계: 여행 완료
✅ **확인 사항**:
- [ ] "여행 완료하기" 버튼을 누르면
- [ ] 완료 확인 모달이 나타나는가?
- [ ] "완료" 버튼 클릭 시 아카이브로 이동하는가?

### 14단계: 내 아카이브 (/my-archive)
✅ **확인 사항**:
- [ ] 완료된 여행 카드가 표시되는가?
- [ ] 여행 제목, 날짜, 장소가 보이는가?
- [ ] 정렬 옵션 (최신순, 오래된순)이 있는가?

**액션**: 여행 카드 클릭

### 15단계: 아카이브 상세 (/my-archive/details/[id])
✅ **확인 사항**:
- [ ] 여행 커버 이미지가 표시되는가?
- [ ] 지도가 표시되는가?
- [ ] 탭 (타임라인, 사진, 지도)이 있는가?
- [ ] 타임라인에서 날짜별 미션이 보이는가?
- [ ] 완료한 미션에 사진이 표시되는가?
- [ ] 하단에 통계 (방문 장소, 사진, 미션)가 있는가?
- [ ] "카카오톡 공유하기" 버튼이 있는가?

### 16단계: 둘러보기 (/others-journey)
✅ **확인 사항**:
- [ ] 다른 사용자의 여행 포스트가 표시되는가?
- [ ] 좋아요, 댓글, 조회수가 표시되는가?
- [ ] 좋아요 버튼이 작동하는가? (즉시 UI 업데이트 - Optimistic Update)
- [ ] 댓글 버튼 클릭 시 댓글 모달이 열리는가?
- [ ] 댓글 작성이 가능한가?
- [ ] 공유 버튼 (카카오톡)이 작동하는가?

### 17단계: 마이 페이지 (/my-page)
✅ **확인 사항**:
- [ ] 프로필 정보 (닉네임, 레벨, 포인트)가 표시되는가?
- [ ] 경험치 바가 표시되는가?
- [ ] 탭 (배지, 캘린더, 통계)이 작동하는가?
- [ ] "포인트 자세히 보기" 클릭 시 /points로 이동하는가?
- [ ] "프로필 수정" 버튼이 있는가?

**액션**: "프로필 수정" 클릭

### 18단계: 프로필 수정 (/my-profile)
✅ **확인 사항**:
- [ ] 닉네임, 이메일, 소개 입력 필드가 있는가?
- [ ] "저장" 버튼이 있는가?
- [ ] "비밀번호 변경" 버튼이 있는가?
- [ ] "로그아웃" 버튼이 있는가?
- [ ] "회원 탈퇴" 버튼이 있는가?
